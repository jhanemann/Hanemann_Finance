Dados

Backup

Exporta todas as movimentações, categorias, investimentos e o financiamento em um único arquivo .json.

Importação

Restaura um backup exportado anteriormente. Compatível com versões anteriores — campos ausentes usam os valores atuais.

Armazenamento

Arquivo local (ex: pasta do OneDrive)

Conecta um arquivo .json real no seu computador — se ele estiver dentro de uma pasta sincronizada (OneDrive, Google Drive, etc.), o backup sobe sozinho pra nuvem também. Assim, uma limpeza de dados do navegador não apaga tudo. Disponível no Chrome, Edge e Opera.

Celular e computador

Sincronização com OneDrive

Mantém os mesmos dados no celular e no computador. O app guarda uma cópia numa pasta privada da sua conta Microsoft (Arquivos › Aplicativos) e a atualiza sozinho a cada alteração. Se os dois aparelhos divergirem, o app pergunta qual versão usar e guarda a outra como cópia — nada é apagado em silêncio.
